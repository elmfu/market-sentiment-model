# MacBook Neo Market Intelligence — v3 Dashboard

Multi-source consumer sentiment analysis for the **MacBook Neo** across Best Buy, Reddit, Hacker News, and DEV.to. Produces a fully self-contained browser dashboard for a **Windows PC OEM competitive intelligence team**.

- **Data period:** 2026-03-04 → 2026-04-28 (55-day launch window)
- **Total signals:** ~33,920 (posts, comments, reviews, articles)
- **Dashboard version:** v3.5 overrides

---

## Quick Start — No Setup Required

Open [`standalone_v3.html`](standalone_v3.html) directly in any browser. All data is baked in — no server, no Python, no internet connection needed.

For the live API-backed version:

```bash
pip install -r requirements.txt
uvicorn api_v3:app --reload --port 8005
# Then open dashboard_v3.html in your browser
```

## File Structure

```
MacBook Neo Model/
├── dashboard_v3.html          ← Live dashboard (requires API server on port 8005)
├── standalone_v3.html         ← Self-contained offline dashboard (no server needed)
├── api_v3.py                  ← FastAPI backend — port 8005
├── database_v3.py             ← SQLite schema + CRUD helpers
├── analysis_v3.py             ← Sentiment, topics, S/W, wordcloud logic
├── build_standalone.py        ← Bakes standalone_v3.html from live DB + overrides
├── build_v35.py               ← Generates data/dashboard_overrides_v3_5.json from DB
├── export_for_llm.py          ← Exports DB snapshot for LLM context
├── style-guide.css            ← Design system (embedded in standalone build)
├── requirements.txt           ← Python dependencies
├── data/
│   ├── dashboard_overrides_v3_5.json  ← Pre-computed S/W, topics, quotes, wordcloud
│   ├── CHANGELOG_v3_5.md              ← Override spec and build notes
│   ├── bby_databasev3/
│   │   └── bestbuy_reviews.json       ← 715 verified purchaser reviews
│   ├── reddit_databasev3/
│   │   ├── posts.json                 ← 20,390 Reddit posts
│   │   └── comments.json             ← 12,395 Reddit comments (31 MB)
│   ├── hn_databasev3/
│   │   └── hn_items.json             ← 325 Hacker News items
│   └── devto_databasev3/
│       └── devto_items.json          ← 95 DEV.to articles
└── docs/
    └── index.html                    ← GitHub Pages (mirrors standalone_v3.html)
```

> **Note:** The SQLite database (`reddit_large_apr_v2.db`) is not included — it's a large binary generated by the scraper. The JSON files in `data/` contain the same records and are the canonical data source for rebuilding.

## Data Sources

| Platform | Records | Method |
|---|---|---|
| Reddit posts | 20,390 | Pullpush.io + Reddit JSON API |

| Hacker News | 325 items | HN Algolia API |
| DEV.to | 95 articles | DEV.to public REST API |
| **Total** | **~33,920 signals** | |

## Rebuilding the Standalone File

If you update the override JSON or dashboard HTML, regenerate the standalone build:

```bash
# From MacBook Neo Model/ directory
# 1. Regenerate overrides from DB (requires reddit_large_apr_v2.db)
python build_v35.py

# 2. Bake standalone HTML
python build_standalone.py
# Output: standalone_v3.html (~327 KB, fully self-contained)
```
